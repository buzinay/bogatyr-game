# Графика «Избы»

Дата: 14.11.2026. Источник: материалы заказчика. Оригиналы PNG и PSD в `Изба/` не изменялись. Машинный перечень `ASSET_MANIFEST.json` содержит исходные пути, SHA-256 оригиналов, размеры холстов, границы обрезки и пути рабочих копий.

## Состав композиции

| Назначение | Источник / рабочий файл | Примечание |
|---|---|---|
| Фон | `Изба_фон.png` → `izba-background.png` | Уже содержит печь, лавку и подушки; интерактивных находок на нём нет |
| Композиционный образец | `Изба_разобранная.png`, `Изба_собранная.png` | Только референсы, не игровые фоны |
| Герой | `Богатырь_раздетый.png` → `hero-base.png` | Босиком, без найденной экипировки |
| Передний план | `Печка.png`, `Лавка.png`, `Подушка .png` | Точно совмещённые перекрытия, не дополнительная мебель в других координатах |
| Кольчуга | `Кольчуга спрятанная.png`, `Кольчуга одетая.png` | Спрятана на печи; надевается выше красного кушака |
| Шлем | `Шлем спрятанный.png`, `Шлем одетый.png` | Частично закрыт лавкой |
| Кушак | `Пояс спрятанный.png`, `Пояс одетый.png` | Красный тканевый слой под кольчугой, независимо от порядка действий |
| Перстень | `Кольцо спрятанное.png`, `Кольцо одетое.png`, `Перстень.png` | На полу рядом с лавкой; тайник увеличен до 80×58 на холсте 1600×1200; отдельное полное изображение карточки |
| Сапоги | Два спрятанных и два надетых сапога | Единая находка, две видимые накладки |
| Гусли | `Гусли спрятанные.png` | По образцу частично за левой границей; для полной карточки — прежний `Богатырь исходные картинки/Игра_гусли.png` |
| Кубок | `Кубок спрятанный.png` | Экспорт слоя отличается от референса по вертикали; размещён у края печи x=851, y=465, как в образце композиции |

Позиции остальных находок и базового героя сохранены по общему холсту художника. Слои обрезаны только в рабочих копиях. Поисковый и надетый варианты разделены; исчезновение вещи из тайника не изменяет её изображение в карточке.

Готовый объединённый `Богатырь_одетый.png` используется как референс: в игре герой складывается из реальных надетых слоёв, поэтому отображает промежуточные состояния. Итоговая картинка также строится из этих слоёв.

Кольчуга уже содержит нарисованный коричневый ремень. Он не является отдельным красным кушаком. Новое указание заказчика о кушаке под кольчугой имеет приоритет над старой формулировкой спецификации о видимом поясе.

Новые рисунки, внешние изображения и нейрогенерация не использовались. Для данного этапа недостающих графических файлов нет. Аудиофайлов пока нет, в конфигурации `sound: null`.
