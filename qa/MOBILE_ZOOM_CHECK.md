# Мобильный масштаб

Начальный масштаб — общий вид на всех устройствах. На экранах до 700 px реплика при входе скрыта, включается кнопкой «Реплика» и располагается снизу поля.

Внутри игрового поля: два пальца увеличивают/уменьшают сцену вокруг середины жеста; один палец перемещает увеличенную сцену. Минимальный масштаб — вся сцена целиком, максимальный — 2 экранных пикселя на пиксель исходника. Кнопка «Показать целиком» сбрасывает ручной масштаб. Оригиналы изображений не меняются.

Проверка `node qa/check-mobile-zoom.cjs` выполнена в Chrome с эмуляцией касаний через CDP на ширинах 320, 390, 768, 1366 px: начальная сцена помещается, мобильная реплика скрыта, двухпальцевое увеличение работает, карточки от жеста не открываются, общий вид восстанавливается кнопкой. Проверка на физическом телефоне остаётся за пользователем.
