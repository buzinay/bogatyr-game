# «Богатырский поход»: первая играбельная сцена «Изба»

Версия izba-5: в карточки Сокровищницы подключены семь новых файлов `* карточка.png`, переданных заказчиком. Они используются и при открытии полной карточки артефакта.

Обновление `izba-2`: убрана шапка, поле на десктопе помещается по высоте окна. Сокровищница открывается всплывающей панелью по кнопке. Реплика находится поверх поля; её можно скрыть крестиком и вернуть кнопкой «Реплика». При наведении предметы подсвечиваются без анимации. Карточка сапог показывает пару, карточка шлема — вертикальный вариант. После обновления файлов нажмите Ctrl+F5 в игре; сохранение совместимо.

Сборка от 14.11.2026. Самостоятельная браузерная игра на HTML/CSS/JavaScript. Поиск семи вещей, пять действий одевания, точные тексты карточек, раскрывающаяся Сокровищница, подсказка, сохранение и завершение сцены. Поляна, лес и камин пока не реализованы. Ничего не опубликовано.

## Самый простой запуск на этом компьютере

1. Дважды нажмите **«Запустить Избу.cmd»** в папке проекта.
2. Дождитесь открытия игры в браузере. Адрес: `http://127.0.0.1:4173/`.
3. Оставьте окно запуска открытым на время игры. Нажмите Enter в этом окне, когда захотите остановить просмотр.

Запуск использует установленный Node.js либо Node.js из локального комплекта Codex. Он ничего не скачивает. Если порт 4173 занят, программа сообщит об этом; посторонний процесс она не останавливает.

Это локальный просмотр только на компьютере. Адрес `127.0.0.1` на телефоне указывает на сам телефон и не откроет игру с компьютера. Для проверки на настоящем телефоне потребуется отдельно разрешённый доступ по локальной сети либо будущий статический хостинг. Мобильная проверка этой сборки выполнена эмуляцией касаний и размеров экрана в Chrome.

## Запуск из терминала

Откройте терминал в папке проекта и выполните:

```text
node tools/serve.cjs
```

Затем откройте `http://127.0.0.1:4173/`. Остановить сервер можно Ctrl+C. Если Node.js не установлен, при наличии Python 3 подойдёт:

```text
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Игра запускается через HTTP. Открытие `index.html` двойным щелчком через `file://` не подходит: браузер не разрешит загрузку JSON.

## Как играть

- Нажмите «Начать поход», а при сохранённой игре — «Продолжить».
- Ищите семь предметов на рисунке. Открытие карточки засчитывает находку, но не надевает её.
- Нажмите «Надеть», «Подпоясать» или «Обуть». Карточку можно закрыть и вернуться к ней через Сокровищницу — это коллекция найденных вещей.
- Красный кушак находится **под кольчугой**. Если кольчуга надета первой, богатырь приподнимает её и подвязывает кушак снизу; действие мгновенное, без анимации. Карточка поясняет, что кушак надет, хотя он скрыт доспехом. Нарисованный на слое кольчуги коричневый ремень — часть изображения кольчуги, а не найденный красный кушак.
- Сапоги — одна находка; на богатыре появляются оба. Гусли и кубок остаются в избе с галочками.
- «Подсказка» выделяет ещё не найденную вещь и показывает нужный участок сцены. Когда всё найдено, но экипировка неполная, она открывает карточку недостающей вещи.
- На телефоне перемещайте рисунок пальцем. Мышью тяните фон либо пользуйтесь полосами прокрутки. «Показать целиком» помещает весь рисунок в окно, «Крупнее» возвращает подробный вид/увеличивает его.
- Для клавиатуры: Tab — переход по элементам, Enter/пробел — действие, Escape — закрытие карточки. В зоне сцены можно использовать клавиши прокрутки.
- При 7 находках и 5 надетых вещах появляется «На поляну». В этой сборке она открывает экран «Первая сцена пройдена», откуда можно вернуться в избу.
- Новая игра: «Меню» → «Начать заново» → подтверждение.

## Где менять тайники

**Основной файл: `dist/config/izba.json`.** Координаты даны в пикселях исходного холста 1600×1200, а не экрана телефона. Масштаб рисунка и областей нажатия меняется совместно.

| Поле | Что менять |
|---|---|
| `items.<id>.hidden` | Место предмета в избе: `x`, `y`, `width`, `height`, `z` |
| `items.<id>.worn` | Место надетой экипировки на богатыре; не менять при переносе тайника |
| `hitAreas.<id>` | Области нажатия: набор многоугольников в координатах сцены |
| `layers` | Передние слои печи, подушки, лавки и базовая фигура героя |
| `items.<id>.cardImage` | Отдельная картинка карточки |
| `items.<id>.sound` | Будущий аудиофайл; сейчас везде `null` |

ID: `chainmail` — кольчуга, `helmet` — шлем, `belt` — кушак, `ring` — перстень, `boots` — сапоги, `gusli` — гусли, `cup` — кубок.

Чтобы переместить тайник вместе с зоной нажатия, удобнее использовать помощник. Например, из корня проекта:

```text
node tools/move-hideout.cjs ring 30 -10
```

Это сдвинет перстень на 30 пикселей вправо и на 10 вверх. Позиция перстня на руке останется прежней. Необязательное четвёртое число меняет размер относительно левого верхнего угла группы:

```text
node tools/move-hideout.cjs ring 0 0 1.2
```

Это увеличит тайник и зону нажатия на 20%. Перед правкой сделайте копию JSON. После изменения обновите страницу и проверьте предмет: печь или лавка могут перекрыть его в новом месте. Уже надетые вещи скрыты с исходных мест — для проверки всех тайников начните новую игру.

Области нажатия большинства предметов подготовлены по видимой прозрачности с учётом перекрытий. Дополнительно игра проверяет прозрачность в точке клика, чтобы не засчитывать пустые поля PNG и предметы за передним планом. Для перстня намеренно оставлена небольшая расширенная зона касания; его изображение увеличено на прежнем участке пола.

## Как менять картинки, тексты и звук

- Оригиналы художника в `Изба/` не изменены. В `dist/assets/` лежат рабочие копии, обрезанные по прозрачным полям; исходные смещения сохранены в настройках и `ASSET_MANIFEST.json`.
- Если новая картинка имеет тот же размер и назначение, замените соответствующий файл в `dist/assets/`. При другом размере/позе обновите также размеры, координаты, зоны нажатия и порядок перекрытий в конфигурации.
- Качество карточек зависит от полей `cardImage` и `treasuryImage` в `dist/config/izba.json`. Сейчас пять карточек используют крупные исходники `*-card-hq.png`; при появлении новых файлов замените эти поля на их обрезанные копии.
- Для полного изображения гуслей в карточке использован уже имеющийся `Богатырь исходные картинки/Игра_гусли.png`: в новой сцене гусли намеренно выходят за левую границу, поэтому их поисковый слой неполный. Нового рисунка для этой карточки не требуется.
- Тексты семи карточек находятся в `dist/content/izba.json`. `description` — определение, `moreReading.title` — произведение, `excerpt` — точный отрывок, `sourceUrl` — ссылка. Статус `customer_supplied` разрешает показ; `draft` у дополнительного чтения скрывает кнопку. Отображаемые тексты не вставляются как HTML.
- В этом этапе нет новых вопросов-викторин: задания — поиск и одевание по спецификации. Название и порядок действий привязаны к стабильным ID; не меняйте ID при правке названий.
- Для подключения готового звука положите файл, например, в `dist/assets/audio/`, а вместо `null` у предмета укажите `"assets/audio/ring.mp3"`. После обновления появятся кнопка повторного прослушивания и переключатель звука. Не указывайте путь, пока файл не готов. Отсутствующее/запрещённое аудио не останавливает игру.
- Нет внешних шрифтов, библиотек, CDN или обязательных запросов к сторонним сайтам. Источники открываются только по желанию игрока, в новой вкладке. Сам текст чтения уже входит в комплект.

`tools/prepare_izba.py` — вспомогательная подготовка первоначальных копий через Python/Pillow. Для запуска и размещения игры она не нужна. **Повторный запуск перезапишет ручную расстановку и тексты в JSON**, поэтому сначала сохраняйте свои правки. Для переноса тайников используйте `move-hideout.cjs`, а не повторную подготовку графики.

## Сохранение

Один ключ `bogatyr-game:izba:v1` в localStorage: найденные вещи, надетая экипировка, завершение и настройка звука. Прогресс восстанавливается кнопкой «Продолжить». Повреждённое сохранение даёт понятное уведомление; запрет хранилища оставляет возможность играть в памяти до закрытия страницы.

Сохранение относится к этому браузеру и адресу сайта, включая протокол и порт. Другой телефон, другой домен или очистка данных браузера не сохранят прежний прогресс. Ничего не отправляется на сервер.

## Готовый комплект для статического хостинга

- `dist/` — готовая игра: HTML, CSS, модуль JavaScript, JSON и PNG. Сборщик и установка npm-пакетов не требуются.
- `bogatyr-izba-v1.zip` — содержимое `dist/`; его можно распаковать в выбранную папку хостинга после отдельного разрешения на публикацию.
- Остальная папка проекта — исходные материалы, инструменты, инструкции и отчёты. Публиковать PSD и исходную рабочую папку не требуется.

Игра поддерживает корень сайта и подкаталог, например **условный** `/games/bogatyr/`. Все внутренние пути относительные. Локальный сервер также обслуживает этот тестовый подкаталог.

Будущий хостинг должен раздавать статические файлы по HTTPS и корректные MIME-типы HTML/CSS/JavaScript/JSON/PNG. Серверный Node.js, Python и база данных на хостинге не нужны. `index.html` должен перепроверяться браузером (`Cache-Control: no-cache`); ресурсы версионируются параметром `v=izba-1`. При следующем выпуске изменить версию в `index.html`, ссылке CSS и константе `BUILD` в `app.js`.

Перед обновлением сохраните предыдущий архив; загружайте ресурсы раньше нового `index.html` либо переключайте папку атомарно. Для отката верните предыдущий комплект целиком. Схему сохранения не меняйте без проверки совместимости. Публикация, настройки реального кеша/HTTPS и проверки прямой ссылки выполняются отдельно: эта сборка нигде не размещена.
