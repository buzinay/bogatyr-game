# Аудио: источники и лицензии

Внутренний журнал проекта. Эти сведения не показываются в детской части игры.

Заполнять одну строку на каждый используемый звук по формату:

`артефакт → имя файла → название записи → автор → ссылка на страницу записи → дата скачивания → лицензия`

Дата скачивания: `YYYY-MM-DD`.

Звуки семи предметов избы подключены из локальной папки dist/assets/audio. Воспроизведение ограничено двумя секундами. Пустые строки не означают разрешение использовать случайную запись. Для каждого звука сначала сохранить страницу записи и условия лицензии в папке проекта, например `audio-sources/<artifact-id>/source.html` или PDF/скриншот страницы.

## Правила заполнения

- Указывать страницу конкретной записи, а не только главную страницу библиотеки или поисковую выдачу.
- Сохранять точное название записи и имя автора так, как они указаны на странице.
- Записывать полное название лицензии и требования к атрибуции.
- Если лицензия или право на скачивание неясны, оставить строку незаполненной до проверки.
- Один и тот же файл можно назначить двум малиновым только после явной записи этого решения в обеих строках.
- Если звук не будет использоваться, можно оставить строку с `—`; файл в игру не подключать.
